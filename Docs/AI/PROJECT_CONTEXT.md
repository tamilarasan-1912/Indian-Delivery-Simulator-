# Project Context

## Status
Repository foundation created. Unity project has not yet been generated in this repository.

## Game
Indian Delivery Simulator — first-person/third-person delivery-partner simulation set in a fictional Indian neighborhood.

## Current vertical slice
Wait for order → accept → store pickup → verify package → customer travel → customer contact → OTP → payment → handover → earnings/rating.

## Intended technology
- Unity 6 LTS
- C#
- Git/GitHub
- Blender for custom 3D assets

## Initial environment
- Compact road network
- QuickKart-style grocery store
- Waiting area
- Apartment destination
- Placeholder traffic/pedestrians

## Important implementation principle
Do not attempt the complete city first. Establish a stable vertical slice, validate it, then scale content and simulation systems.

## Repository state
The repository currently contains design/documentation files only. Unity assets, ProjectSettings, Packages, and Assets will be added when the Unity project is created locally and synchronized with GitHub.
